# Privacy policy

Luaumap runs entirely on your computer.

- It reads the Luau/Lua source files and Rojo project file of the project you run it in.
- It writes one index file, `.luaumap/index.json`, inside that project.
- It collects no personal data, makes no network connections, and sends nothing to the author or anyone else.
- It has no accounts, analytics, telemetry or tracking.

Questions: open an issue at https://github.com/zunxo7/luaumap/issues.
